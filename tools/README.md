# Development Tools

This directory contains development utilities, scripts, and tools used during the development process.

## Contents

### Mock Server
Mock server for testing and development purposes when backend is not available.

## Usage

Tools in this directory are for development use only and should not be included in production builds.

## Adding New Tools

When adding new development tools:
1. Create a descriptive directory or file name
2. Add documentation for usage
3. Include any required dependencies in a local requirements.txt or package.json
4. Update this README with tool description

## Best Practices

- Keep tools simple and focused
- Document all command-line arguments
- Add error handling
- Version control tool configurations
